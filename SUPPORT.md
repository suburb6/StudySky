# Support

StudySky is community-maintained self-hosting software with no uptime or response-time guarantee.

- **Setup questions and ideas:** GitHub Discussions
- **Reproducible software defects:** GitHub Issues
- **Security vulnerabilities:** GitHub private vulnerability reporting only
- **Host administration, data recovery, or custom deployment work:** the installation operator

Before asking for help, read the installation, VPS, backup, upgrade, and OCR guides; check release
notes; and collect the StudySky version, host architecture, Docker/Compose versions, failing command,
and redacted logs. Remove emails, domains, IP addresses, tokens, paths, note contents, and document
names.

The maintainers cannot access, repair, back up, or reset an independent installation. There is no
official public StudySky cloud, shared VPS, or registration service.
